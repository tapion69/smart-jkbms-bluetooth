# Smart JK-BMS Bluetooth

Standalone Home Assistant Bluetooth add-on development prototype. Node-RED diagnostics on port **1895**.

Version **0.1.0-dev** is for BLE scan, connection probes and raw events only. JK-BMS data decoding and MQTT Discovery are **not yet implemented**. The source files and installation guidance are included in this repository.

Do not expose port 1895 to the public internet. Use a trusted LAN or VPN and configure a strong Node-RED password.
